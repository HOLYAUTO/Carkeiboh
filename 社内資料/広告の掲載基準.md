# スポンサー広告の掲載基準（案）

HOLY とたにぐち自動車で掲載の可否を決めるためのたたき台です。**決まった内容ではありません。** 決まったら `社内資料/要確認一覧.md` 40 を更新します。

## 1. 枠

| 場所 | 出る位置 | 1回に出す数 |
| --- | --- | --- |
| ホーム | 「もうすぐの期限」の下 | 1件 |
| 維持費 | 一番下 | 1件 |
| 整備工場 | 掲載店の一覧の下 | 1件 |

- 同じ場所に複数の広告があるときは、表示の重みに比例して出す（画面を開くたびに選び直す）
- どの広告にも「PR」と広告主の名前を必ず出す（ステルスマーケティングの規制に合わせ、広告であることを示す）

## 2. 載せてよいもの（案）

- クルマの維持・整備に関わる商品・サービス（オイル、タイヤ、カー用品、洗車、保険、駐車場、ロードサービスなど）
- たにぐち自動車の取引先・地域のお店
- たにぐち自動車自身のキャンペーン

## 3. 載せないもの（案）

- 法令に反するもの、公序良俗に反するもの
- 根拠のない「最安」「No.1」「必ず」などの表示（景品表示法の優良誤認・有利誤認のおそれ）
- 効果・効能をうたう健康食品・化粧品など（薬機法のおそれ）
- 消費者金融・ギャンブル・アダルト・政治・宗教
- **要判断**：たにぐち自動車と競合する整備工場・車検店（整備工場の掲載は「整備工場」タブの掲載店として別に扱う）

## 4. 画像と文言

- 画像：横2：縦1（アプリで自動で切り抜く）、JPEG、2MB まで。文字を画像に入れすぎない（小さい画面で読めないため）
- 題名 40文字、説明 120文字まで。リンクは https:// のページだけ
- 画像は公開の保存場所に置くため、URL を知っていれば誰でも見られる。広告に出せる画像だけを使う

## 5. 申し込みから掲載まで（案）

1. 広告主からの申し込み（窓口は **要判断**：HOLY／たにぐち自動車）
2. 上の基準で審査（審査する人は **要判断**）
3. 運営メニューの「スポンサー広告の管理」で登録し、「公開する」をオンにする
4. 毎月、表示回数・タップ数を広告主に報告する（運営メニューで月ごとに見られる）

## 6. 決めてもらうこと

- 掲載料（月額／表示回数／タップ数のどれで決めるか）と、HOLY・たにぐち自動車の売上の分け方
- 申し込みの窓口と審査する人
- 広告主への報告の形（画面のスクリーンショット／表計算のファイル）と頻度
- 枠を増やすか（例：お知らせの一覧の中）
