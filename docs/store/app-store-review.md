# App Store の審査に出す手順と、入れる内容

ビルドの申請（`eas submit`）は App Store Connect に上げるところまで。**審査に出すのは App Store Connect の画面で行う**
（API で出すには App Store Connect の API キーが要り、このリポジトリには無い）。

## 1. 審査に出す前に埋めること（残り）

| # | やること | 誰が | 状態 |
| --- | --- | --- | --- |
| 1 | プライバシーポリシー・利用規約の【要確認】（住所の番地・代表者・連絡先・制定日など）を埋め、たにぐち自動車の確認を受ける（`docs/legal/`） | たにぐち自動車・HOLY | 未 |
| 2 | 2つを Web に公開する場所を決めて公開し、URL をアプリ（`eas.json` の production の `EXPO_PUBLIC_PRIVACY_URL`・`EXPO_PUBLIC_TERMS_URL` と EAS の production の環境変数）とストアに入れる | HOLY | 未 |
| 3 | 定期購入 `ijilog_plus_monthly`（サブスクリプショングループ「複数台プラン」）と消耗型 `ijilog_restore_fee` を作り、審査用のスクリーンショット・説明を入れて、このバージョンに付ける（`docs/setup.md`） | HOLY | 未確認 |
| 4 | スクリーンショット（6.9インチ：1320×2868 など）を、TestFlight で入れた実機から撮る | HOLY | 未 |
| 5 | カテゴリを決める（仮：ライフスタイル／ファイナンス） | たにぐち自動車 | 未 |
| 6 | 下の「App のプライバシー」「年齢制限」を入れる | HOLY | 未 |

審査用のアカウントは**要らない**：Apple でサインイン、または審査する人のメールアドレスに届くコードでログインでき、初めてのログインでアカウントができる。
審査へのメモは `docs/store/store-listing.md` の4章をそのまま貼る。

## 2. 画面での出し方

1. マイApp → イジログ → 「App Store」タブ → iOS アプリのバージョン（0.1.0）
2. 「ビルド」で 8 を選ぶ（輸出コンプライアンスは `ITSAppUsesNonExemptEncryption: false` を入れてあるので聞かれない）
3. 説明文・キーワード・サポート URL・スクリーンショットを入れる（文面は `docs/store/store-listing.md`）
4. 「App 内課金とサブスクリプション」に 2 つの商品を付ける（1 の #3）
5. 「App Review に関する情報」に連絡先と、メモ（`store-listing.md` の4章）を入れる。「サインインが必要」はオフにする（オンにすると ID・パスワードが必須になる。審査する人は自分でアカウントを作れる）。ログインのしかたはメモに書いてある
6. 「審査用に追加」→「審査へ提出」

## 3. App のプライバシー（App Store Connect → App のプライバシー）

**トラッキング：しない**（外部の広告・計測サービスを使わない。ほかの会社のデータと結びつけない）。
「収集」は、端末の外に送り、その場の処理より長く残すものだけ（写真の読み取りで Claude API に送る写真は保存しないので入れない）。

| データの種類（Apple の区分） | 何が当たるか | 目的 | ユーザーに紐づく |
| --- | --- | --- | --- |
| 連絡先情報 → メールアドレス | ログインのメールアドレス | アプリの機能 | はい |
| 連絡先情報 → 名前 | 車検証の所有者・使用者の氏名 | アプリの機能 | はい |
| 連絡先情報 → 物理的な住所 | 車検証の住所・使用の本拠の位置 | アプリの機能 | はい |
| ユーザコンテンツ → 写真またはビデオ | 愛車の写真 | アプリの機能 | はい |
| ユーザコンテンツ → その他のユーザコンテンツ | 給油・整備・維持費・期限の記録 | アプリの機能 | はい |
| 購入 → 購入履歴 | 複数台プランの購入の記録 | アプリの機能 | はい |
| 位置情報 → おおよその場所 | ガソリンスタンドを調べるときの約5km四方の区画 | アプリの機能 | いいえ |
| ID → ユーザ ID | アカウントの ID | アプリの機能 | はい |
| 使用状況データ → 製品の操作 | 整備工場の画面の操作の記録、入力にかかった時間・入力方法 | 分析、アプリの機能 | はい |
| 使用状況データ → 広告データ | スポンサー広告を表示した・押した記録 | デベロッパの広告またはマーケティング、分析 | はい |
| その他のデータ | 車検証の記載内容（ナンバー・車台番号・型式など） | アプリの機能 | はい |

正確な位置情報は収集しない（端末の中だけで使う）。プライバシーポリシーを変えたら、この表もあわせて直す。

## 4. 年齢制限（年齢制限の質問）

暴力・性的な内容・ギャンブル・薬物・ホラーなどはすべて「なし」。
ユーザーどうしのやりとり（チャット・投稿）：なし。制限のない Web アクセス：なし（規約などを開くだけ）。
広告：あり（スポンサー広告。整備工場・カー用品などで、年齢に関わる内容は載せない）。
→ 4+（または 4+ 相当）になる見込み。
