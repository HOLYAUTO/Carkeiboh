# ストアの説明文（App Store・Google Play）

App Store Connect・Play Console の「ストアの掲載情報」に入れる文面。字数は各欄の上限に収めてある（`python3` で数えた。下の表）。

- 位置情報の書き方は、アプリの中の説明（`src/app/fuel-detect.tsx`）・プライバシーポリシー（`docs/legal/privacy-policy-draft.md` 第6項）・
  Google Play の申告（`docs/store/play-location-declaration.md`）とそろえてある。どれかを変えたら、ほかもあわせて直す
- 料金はまだ仮（`docs/open-questions.md` 30）なので、説明文には書かない（ストアが料金を表示する）
- 「必ず」「No.1」「税理士いらず」のような言い切り・比べる表現は使わない。税の計算は「目安」と書く
- 【要確認】のところは、決まってから埋める

## 2. 詳しい説明（両ストア共通・4000字まで）

```
イジログは、株式会社たにぐち自動車がつくった、クルマの家計簿アプリです。
オイル交換の目安、車検や保険の期限、毎月の維持費が、ひと目で分かります。
計算はアプリにおまかせ。入力した数字と、計算したあとの数字だけをお見せします。

■ 次のオイル交換が分かる
・前回の交換と走行距離から、次の交換の目安をホームに表示します
・オイル・フィルター・タイヤ・ブレーキの記録を残せます
・走行距離は、これまでの走り方から今の距離を見積もって入れておきます（確かめてから保存）

■ 期限を忘れない
・車検・点検・保険などの期限を登録すると、近づいたときに通知でお知らせします
・車検証の満了日を入れると、車検の期限も自動で登録します

■ 入力はかんたん
・レシートやメーターを撮るだけで、金額・日付・走行距離を読み取ります
・レシートをまとめて撮って、一度に登録できます
・話しかけて入力することもできます
・掛けカードの月の明細を撮ると、給油をまとめて登録できます（登録ずみと思われる給油は、はじめから外しておきます）
・保険・ローン・駐車場・自動車税など、毎月・毎年決まった支出は、時期が来たら下書きを用意します
・ホーム画面のアイコンを長押しすると、「給油を記録」「レシートを撮る」をすぐ開けます

■ 給油の記録を忘れない（知らせ方を選べます）
・アプリを開いたときに知らせる：ガソリンスタンドでアプリを開くと、スタンド名を入れた給油の記録をすぐ開けます
・スタンドを出たら通知する：スタンドに数分いて出たときに「給油しましたか？」とお知らせします（位置情報を「常に許可」にしたときだけ）
・使わない：位置情報は使いません
位置情報は端末の中だけで使い、正確な位置はサーバーに送りません。あとから設定でいつでも変えられます。

■ 維持費と燃費をまとめる
・給油・整備・税金・保険など、項目ごと・月ごとの維持費をグラフで表示します
・給油の記録から燃費を計算します
・かけ（掛けカード）で払った給油は、税抜の金額を入れると消費税を足して税込にします

■ 税金と確定申告
・車検証の内容から、自動車税（種別割）と自動車重量税の目安を自動で計算します
・自家用・事業用、乗用・貨物・軽自動車、13年超の重課にも対応します
・仕事で使う割合（家事按分）を入れると、経費にできる額を計算します
・1年分の経費の集計と、明細の表（CSV）を作れます。確定申告の準備にお使いください
※税金の計算は目安です。申告や納税の内容は、ご自身または税理士などの専門家にご確認ください

■ 車検証をまるごと記録
・車検証を撮ると、記載内容を読み取って記録します
・氏名・住所・車台番号は、伏せて表示します（見たいときだけ表示）

■ 整備工場とつながる
・近くの整備工場を探して、ルート検索や電話での予約ができます
・連携した整備工場で受けたオイル交換・タイヤ・ブレーキ・整備・車検の記録を、自動で取り込めます（QRコードを読み取って連携。いつでも解除できます）

■ 複数台プラン
・1台目は無料でお使いいただけます
・家族や仕事のクルマをまとめて登録したいときは、複数台プラン（最大5台・月額・自動更新）をご利用ください
・お支払いは購入の確定時にストアのアカウントに請求されます。期間が終わる24時間前までに解約しない限り、自動的に更新されます。解約はストアのアカウントの設定から行えます

■ プライバシー
・外部の広告配信サービスは使っていません。アプリ内の広告には「PR」と広告主の名前を表示します
・アカウントは、アプリの設定からいつでも削除できます

利用規約：【要確認：利用規約の URL】
プライバシーポリシー：【要確認：プライバシーポリシーの URL】

ガソリンスタンドの場所：© OpenStreetMap contributors
```

## 4. App Store の審査へのメモ（App Review Information → Notes）

「常に許可」の位置情報について、審査で聞かれやすいので先に書いておく。

```
Background location is used only by the optional "Notify me when I leave a gas station" feature
(Settings > 給油の記録のしかた > スタンドを出たら通知する).
The app registers up to 19 nearby gas stations with region monitoring (geofencing) and shows a local
notification "Did you refuel?" when the user stayed 2–60 minutes at a station and then left.
Precise location never leaves the device; only a ~5 km grid cell name is sent to our server to download
the list of nearby gas stations (OpenStreetMap data).
Before requesting "Always" permission, the app shows an in-app explanation and asks for consent.
The default choice is "When I open the app" (when-in-use only), and the user can choose "Off".

Sign-in: No demo account is needed. An account is created on first sign-in.
Please use "Sign in with Apple", or enter any email address you can receive and type the 6-digit code sent to it.
After signing in, register a vehicle (name and current odometer reading are enough) to see the home screen,
reminders and costs. The "Multi-vehicle plan" (auto-renewable subscription) is needed only to register a second vehicle.
```

## 5. あわせて入れるところ

| ストア | 欄 | 入れるもの |
| --- | --- | --- |
| 両方 | プライバシーポリシーの URL | 公開したプライバシーポリシーの URL（アプリの `EXPO_PUBLIC_PRIVACY_URL` と同じもの） |
| App Store | 利用規約（EULA） | 独自の利用規約を使うなら URL を説明文と「使用許諾契約」に入れる（自動更新のサブスクリプションがあるため必須） |
| App Store | App のプライバシー | 位置情報の分：「おおよその位置情報」を「アプリの機能」で収集・ユーザーに紐づけない（サーバーは区画と利用者を結びつけて保存しない）・トラッキングに使わない。正確な位置情報は収集しない。ほかの項目（メールアドレス・写真など）は、プライバシーポリシーの第2項にあわせて入れる |
| Google Play | データ セーフティ | `docs/store/play-location-declaration.md` の3章 |
| Google Play | 位置情報の権限 | `docs/store/play-location-declaration.md` の1章・2章 |
| 両方 | カテゴリ | 仮：プライマリ「ライフスタイル」・セカンダリ「ファイナンス」（App Store）、「自動車」（Google Play の「自動車・乗り物」）。【要確認】 |
