# 手放したクルマの記録の引き継ぎ（設計メモ・未実装）

2026-10-31 の要望。**この段階では作らず、仕様を決めるための材料をまとめる。** 先に「クルマを手放す（乗り換え・廃車）」だけを実装した（`vehicle-release`）。

## いま実装済みのこと

- 乗り換え・廃車で手放したクルマは、アプリに出さないが記録は DB に残す（`vehicles.status`）
- 乗り換えのとき、本人が「次の持ち主に記録を引き継げるようにする」を選べる（`vehicles.history_share_consent`。既定はオフ）
- 廃車のクルマには、イジログではだれも記録を足せない。Ledra には廃車を伝える（`docs/ledra-api-contract.md` 4章。Ledra 側は未実装）
- アカウント削除では、手放したクルマの記録もすべて消える

## 要望の内容

1. 次の持ち主がそのクルマを登録して整備工場と連携したら、過去の記録を**項目（カテゴリ）だけ**見られる
2. 記録の**中身を見るのは有料**（Ledra の有料閲覧と同じ考え方）
3. 料金は**履歴を作った人に還元**する。ただし一般の利用者には還元しない

| 履歴を作った人 | 見る経路 | 還元先 |
| --- | --- | --- |
| 一般の利用者（イジログで自分で記録） | イジログ | HOLY・たにぐち自動車で分配 |
| 整備工場（Ledra の記録） | イジログ | 整備工場・たにぐち自動車 |
| 整備工場（Ledra の記録） | Ledra だけ | 整備工場（一部を手数料としていただくかは検討中） |

## 決める必要があること

| 項目 | 内容 |
| --- | --- |
| 同じクルマだと判断する方法 | イジログは車体番号を持っていない。Ledra の連携で同じ車両と分かったときだけ結び付けるか、車体番号（車検証の読み取りなど）を新しく登録してもらうか |
| 前の持ち主の同意 | 第三者への提供になるため、本人の同意が必要（いまの「引き継げるようにする」の文面を、正式な同意として足りる形にする）。同意しなかった記録・同意する前に手放した記録の扱い |
| 渡す項目 | 候補：作業日・走行距離・作業の種類（オイル・フィルター・車検など）・店舗名。渡さない：氏名・連絡先・メモ・写真・金額 |
| 課金の方法 | アプリの中で記録を買う形は、App Store・Google Play の課金を使う決まり（手数料が引かれる）。1件ごと・1台まとめて・月額のどれにするか |
| 分配の方法 | 整備工場・たにぐち自動車・HOLY への支払いの仕組み（請求・振込の頻度、手数料、税の扱い） |
| Ledra との分担 | Ledra 側の記録の有料閲覧との関係、料金の受け渡し、API の追加 |
| 法務 | 利用規約・プライバシーポリシーの改定、特定商取引法の表示、前の持ち主からの削除の求めへの対応 |
