# エラーコード表

アプリが出すエラーには、必ず `IJ-` で始まるエラーコードを付けます。画面の「エラーコード：IJ-XXX-000」を、この表で引いてください。

- コードの一覧（アプリ側）は `src/lib/error-codes.ts` の `ERROR_CODES` です。コードを足したり消したりしたら、この表も同じように直します。`tests/lib/error-codes.test.ts` で、両方のコードがそろっているかを確かめています。
- 1つのコードには、1つの原因の種類だけを割り当てます。ほかの原因とまぎらわしいときは、新しいコードを作ります。
- 画面には、利用者向けの文に加えて、ストアやサーバーから返ってきた元の文（「ストア：…」「DB 42501」など）も括弧で出します。原因を調べるときは、その元の文も控えてください。

| コード | 何が起きたか | 主な原因 | 利用者の対処 | 運営・開発の対処 |
| --- | --- | --- | --- | --- |
| IJ-NET-001 | 通信できなかった | 電波が弱い・機内モード・サーバーに届かない | 電波の良いところで、もう一度試す | 続くときは Supabase の状態（ダッシュボード）とログを確認する |
| IJ-AUTH-001 | ログインの有効期限が切れた | 長く開いていなかった・ログアウトされた | ログインし直す | 多発するなら Supabase Auth のログ・トークンの設定を確認する |
| IJ-DB-001 | 権限がない | 他人・他社のデータを変えようとした、RLS（行の権限）に合わない（DB 42501） | — | `supabase/migrations` の RLS を確認する。`npm run test:rls` で再現を試す |
| IJ-DB-002 | 同じ内容がすでにある | 一意の制約に当たった（DB 23505） | 同じものが登録済みか確かめる | 二重送信になっていないか、画面の送信処理を確認する |
| IJ-DB-003 | 値を保存できない | 必須の項目が空・範囲外・制約に合わない（DB 23502・23514・23503・22xxx・P0001） | 入力を見直す | 括弧内の元の文で、どの制約かを確かめる |
| IJ-DB-004 | データが見つからない | 削除済み・掲載終了・別のアカウントで開いた（PGRST116） | 一覧から開き直す | 削除・非公開の状態を確認する |
| IJ-DB-009 | その他のデータベースのエラー | 上のどれにも当てはまらない読み書きの失敗 | 時間をおいて試す | 括弧内の DB のコードと Supabase の Postgres のログを確認する |
| IJ-FN-001 | サーバーの処理がエラーを返した | Edge Function が失敗を返した（括弧内に関数名と HTTP の番号） | 時間をおいて試す | Supabase の Edge Function のログで、その関数を確認する |
| IJ-FN-002 | サーバーの処理に届かなかった | 関数への中継の失敗 | 時間をおいて試す | 関数がデプロイされているか、Supabase の状態を確認する |
| IJ-PERM-001 | カメラ・写真の許可がない | 端末の設定で許可していない | 「設定を開く」からカメラを許可する | — |
| IJ-PERM-002 | 位置情報の許可がない | 端末の設定で許可していない | 「設定を開く」から位置情報を許可する | — |
| IJ-PERM-003 | 通知の許可がない | 端末の設定で通知をオフにしている | 「設定を開く」から通知を許可する | — |
| IJ-PERM-004 | マイク・音声認識を使えない | 許可していない、または端末が音声認識に対応していない | マイクと音声認識を許可する。使えない端末では手で入力する | — |
| IJ-VOICE-001 | 音声を聞き取れなかった | 無音・時間切れ・音声認識のエラー（括弧内にエラーの種類） | もう一度話す | 括弧内の種類が続くなら、音声認識の設定を確認する |
| IJ-APP-001 | 地図アプリ・ブラウザを開けなかった | 開けるアプリがない | 地図アプリ・ブラウザを入れる | — |
| IJ-QR-001 | QRコードを読み取れなかった | QR の内容が正しくない・読み取りに失敗した | 整備工場の QR を読み取り直す | QR の中身の形式を確認する |
| IJ-NAV-001 | 画面を開く情報が足りない | 古いリンク・通知から開いた | 一覧から開き直す | リンク・通知の作り方を確認する |
| IJ-BIL-001 | ストアにつながらない | ストアとの接続・商品の読み込みに失敗した（括弧内にストアのコード） | 時間をおいて「もう一度読み込む」 | 有料アプリ契約・銀行口座・税金の状態（App Store Connect の「ビジネス」、Play Console のお支払いプロファイル）を確認する |
| IJ-BIL-002 | ストアに複数台プランがない | 商品（`ijilog_plus_monthly`）が未作成・未承認・配信国に日本がない | 時間をおいて試す | App Store Connect／Play Console で商品の状態・価格・配信国を確認する |
| IJ-BIL-003 | ストアの国・地域が日本でない | ストアのアカウントの国・地域が日本以外（括弧内に国・地域）。アプリは日本だけで配信しているため、その国では買えない | Apple ID（Google アカウント）の国・地域を日本にする。テスト用アカウントは国・地域を日本で作る | アプリの配信国（「価格および配信状況」）と、テスト用アカウントの国・地域を確認する |
| IJ-BIL-004 | ストアの手続きが途中で終わった | 利用者が購入の画面を閉じた。または Apple・Google が購入の手前で止めた（サインインに失敗した、そのストアでは買えない、など） | もう一度「申し込む」を試す。購入の画面が出ないまま続くなら、表示されたエラーコードを伝える | 括弧内のストアの文とストアの国・地域を確認する。国・地域が日本以外なら IJ-BIL-003 と同じ対処。契約・商品の状態も確認する。**Sandbox アカウントで起きたら、App Store Connect の Sandbox テスターの「割り込み購入」（interruptPurchases）がオフか確かめる**（オンだと購入がわざと中断される） |
| IJ-BIL-005 | お支払いの完了を待っている | 保護者の承認待ち・コンビニ払いなど | お支払いが済めば自動で有効になる | 長く続くなら billing-reconcile の実行とログを確認する |
| IJ-BIL-006 | 購入を確認できなかった | 購入はストアで済んだが、サーバー（billing-verify）での確認に失敗した（括弧内に元のコード） | 時間をおいて「購入を復元」 | billing-verify のログと、ストアの API キー（Edge Function の secrets）を確認する |
| IJ-BIL-007 | Google Play の料金プランを読み込めない | 定期購入の基本プラン（offer）が有効になっていない | 時間をおいて試す | Play Console で基本プランが有効か確認する |
| IJ-BIL-008 | ストアでその他のエラー | 上のどれにも当てはまらないストアのエラー（括弧内にストアのコード） | 時間をおいて試す | 括弧内のストアのコードを、expo-iap（OpenIAP）のエラーコードで調べる |
| IJ-UNK-000 | 思いがけないエラー | 分類できなかったエラー | アプリを開き直して試す | 括弧内の元の文で調べ、必要なら新しいコードを作ってこの表に足す |

| 日付 | コード | 起きたこと | 原因 | 対処 |
| --- | --- | --- | --- | --- |
| 2026-11-13 | IJ-BIL-001 | 料金が「読み込めませんでした」になり、申し込めない | 有料アプリ契約が「処理中」（銀行口座の確認待ち） | App Store Connect の「ビジネス」で契約が「有効」になるのを待つ |
